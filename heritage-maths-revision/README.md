# Heritage Academy Mathematics Revision Portal

**Development-only. Not approved for student use.**

This directory is isolated from the existing chapter pages in the repository.

## Scope
- Secondary 1 and Secondary 2, Paper 1 and Paper 2
- Three sets per paper planned, 50 marks per set
- 20% Semester 1 / 80% Semester 2 marks
- 50% basic / 40% moderate / 10% challenging marks
- Laptop-first layout, MathJax-rendered equations, progressive hints

## Confidentiality
No confidential 2026 SA2 examination papers, marking schemes, screenshots, similarity comparisons, or source extracts may be committed to any branch of this public repository.

The sample question in this development scaffold is illustrative and does **not** constitute any of the planned 12 approved practice sets. New question content must be independently reviewed before publication.

## Preview
Run `python -m http.server 8000` at the repository root and visit `http://localhost:8000/heritage-maths-revision/`.

## Release gate
Do not link this directory from the student homepage or enable it as the published Pages source until mathematical, curriculum, functional, accessibility and confidentiality review is complete.
