# Real student-script moderation protocol

**Status:** Awaiting anonymised real student work. No automatic method-mark scoring is authorised.

## Scope
Start with Heritage Academy Secondary 1 Mathematics, Paper 1, Set 1. Use the ten draft questions and the teacher-facing rubric already in this folder.

## How to collect evidence
1. Ask students to complete practice questions on paper, showing full working. Do **not** use the confidential SA2 examination scripts for this public-repository workflow.
2. Remove names, faces, school IDs, candidate numbers, handwriting labels that identify the student, and other personally identifying content **before** sharing scripts.
3. Assign neutral script IDs (S01, S02, etc.). Keep the identifying key offline, outside GitHub.
4. Store student scans and teacher marking records in an appropriately access-controlled school location, **not in this public repository**. This repository contains the blank recording template only.

## Blind moderation
- Teacher A and Teacher B independently mark the same anonymised parts, without seeing the other's marks.
- Record each proposed M and A point separately, plus alternative method and follow-through reasoning.
- Only after both sets are complete, compare total marks and disagreements.
- Resolve disputed cases through a documented moderation decision and revise the rubric where required.
- A suggested initial pilot is 5–10 anonymous scripts across easy, moderate and challenging questions. This is a practical pilot size, not a statistical guarantee.

## Checks before proposing automatic method marks
- Both raters have completed marking independently.
- Every disagreement in method points and follow-through is reviewed and resolved.
- Correct alternative solutions receive full appropriate credit.
- Final-answer correctness alone does not imply M marks.
- A clear policy exists for units, significant figures, decimal places, and follow-through.
- Each question is pedagogically suitable for its allocated marks.
- No scoring model is enabled without teacher approval and a separate validated implementation.
