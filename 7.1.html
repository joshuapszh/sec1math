Section 7.1: Sequences

🎯 Chapter Targets:
  • Recognise simple number patterns/sequences and state the rules for the sequences.
  • Continue a given sequence.
  • Find the terms of a sequence.
  • Find a formula (an algebraic expression) for the general term (nth term) of a sequence.
  • Use number patterns in real-world contexts.
📚 Concept Reference: Sequences

• A number pattern/sequence is an ordered list of numbers which follow a particular rule.
• Each number in the sequence is called a term. (e.g., in 7, 9, 11, 13... First term = 7, Second term = 9).
• Most sequences involve adding/subtracting or multiplying/dividing to find one term from the one before it.

Special Number Patterns:
• Perfect square numbers: 1, 4, 9, 16, 25...
• Perfect cube numbers: 1, 8, 27, 64, 125...
• Prime numbers: 2, 3, 5, 7, 11, 13...
• Triangular numbers: 1, 3, 6, 10, 15...
• Fibonacci numbers: 1, 1, 2, 3, 5, 8, 13... (Rule: Add the two previous terms to get the next term).
